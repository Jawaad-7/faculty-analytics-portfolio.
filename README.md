# Faculty Analytics Dashboard (2023-2025)

## Project Overview
During my Data Analytics Internship at DUT, I developed a comprehensive reporting solution to analyze institutional performance and student demographics using Oracle SQL and Power BI.

## Tech Stack
*   **Data Source:** Oracle Database
*   **Transformation:** SQL Queries and Database Views
*   **Visualization:** Power BI

## The Problem
The institution needed a reliable way to track student enrollment, demographics, and performance metrics across different faculties without manual data manipulation.

## The Solution
I wrote complex SQL queries to extract and validate data from the Oracle database and built this interactive Power BI dashboard. The dashboard allows users to filter by Faculty and Year to view real time metrics.

![Faculty Analytics Dashboard](faculty_dashboard.png.png)

## Key Insights Tracked
*   Total Student Enrollment and NSFAS student ratios.
*   Student demographic breakdown (Nationality and Race).
*   Enrollment trends over a three year period.
*   Student distribution across different faculties.
